# Create a new note

The fastest way to create a new note from the current subtitle is:

1. Open a video in mpv.
2. Pause on the subtitle you want.
3. Press <kbd>a</kbd> to open the advanced menu.
4. Press <kbd>Ctrl+n</kbd>.

That exports a new Anki note using the currently active field set and the current capture/timing state.

## Using multiple subtitle lines

If the sentence spans more than one subtitle, use the advanced menu to capture and time the full range:

1. Press <kbd>a</kbd> to open the advanced menu.
2. Press <kbd>c</kbd> to capture from the current subtitle and begin building the selection.
3. Move through nearby subtitle lines with <kbd>alt+q</kbd> and <kbd>alt+e</kbd> inside the menu, or use the global subtitle navigation bindings outside the menu.
4. Adjust timings with <kbd>s</kbd>, <kbd>f</kbd>, <kbd>S</kbd>, and <kbd>F</kbd> if needed.
5. Press <kbd>Ctrl+n</kbd> in the menu to export the note.

See [core workflows](./core_workflows.md#subtitle-capture-and-timing) for the other capture and timing controls.

## If you want Anki's Add Cards window

If you want to open Anki's GUI add-card flow instead of silently adding the note, use:

- <kbd>Ctrl+G</kbd> inside the advanced menu

That uses AnkiConnect's `guiAddCards` path and opens the Add Cards window prefilled with the generated fields.
Opening the window is only a handoff: the note is not created until you save it in Anki. MPV Anki Clips reports that the window opened and does not record the note as exported at that point.

## Notes

- Direct note creation is confirmed by reading the created fields back from Anki. If the request outcome is ambiguous, check Anki before trying again; MPV Anki Clips does not automatically retry note creation.
- After the note is created, you can usually find it in the Anki Browser with `added:1`.
- Dictionary definitions are not generated by this export path. Add them separately with your preferred tool if your note type expects them.
